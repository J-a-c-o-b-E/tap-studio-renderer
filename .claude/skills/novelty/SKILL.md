# Novelty

The same product gets many videos. Each one needs its own angle, or the ads fatigue and look like duplicates.

## Pick one angle

Use the job's `brief` first. If it leaves room, choose one and say which in the summary:

| Angle | Hook pattern |
|---|---|
| Objection | "No followers? No product? No face?" → none of that is needed |
| Wrong order | "Everyone says build first" → the other way round |
| Tiny start | A brand-new account, one follower, a small real detail |
| What's inside | Open the box: the lessons, the 1-on-1, what happens after you join |
| Price contrast | Everything listed, then the small price |
| Question | "Ever wondered how people post for brands?" |
| Mistake | "Stop doing X before you try this" (only if the brief supports it) |

`job.metadata.avoid_angles` (if present) lists angles already used: pick another.

## Vary on purpose

- **First scene.** Rotate between `pills`, `strike_list`, `headline`, `profile`, `footage`. The first scene decides whether two videos look alike.
- **Order of proof and product.** Sometimes numbers first, sometimes the box first.
- **Wording.** New hook line every time; never reuse a hook from the example plans.
- **Background order.** Start on a different colour than the examples do.

## Keep fixed

The facts, the price, the brand look, the end card, and the safety rules. Novelty is in the angle and the edit, never in the claims.
